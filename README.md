# 똥강아지

Godot 4.6용 2.5D 수직 플랫포머 프로토타입. 할머니 집 마당에서 생활용품 발판 20개를 지나 높이 32.2m의 지붕까지 올라갑니다. 외부 에셋이나 플러그인 없이 실행됩니다.

## 실행

Godot에서 `project.godot`을 가져온 뒤 F6이 아닌 **F5**로 프로젝트를 실행합니다.

macOS 터미널:

```sh
/Applications/Godot.app/Contents/MacOS/Godot --path /Users/iyeseul/Documents/yeaseul/ddong_puppy
```

## 조작

| 입력 | 동작 |
| --- | --- |
| A / D 또는 ← / → | 좌우 이동 |
| Space | 점프, 공중에서 다시 눌러 2단 점프 |
| W 또는 ↑ 누르고 있기 | 위쪽 경로 살펴보기 |
| E | 중간 평상의 배변 장소에서 체크포인트 저장 |
| R | 체크포인트 복귀, 없으면 마당으로 복귀 |
| Esc | 일시정지 / 계속 |
| N 2초 누르기 | 진행 초기화 |

사망이나 자동 부활은 없습니다. 발판 아래로 떨어지면 하단 발판 또는 기본 바닥에 착지해 그대로 계속합니다. 이동 범위는 X ±8m이며 기본 바닥은 그 바깥까지 이어집니다. R은 수동 체크포인트 복귀 기능입니다.

착지 중 2초 간격으로 자동 저장하며 창을 닫으면 공중에서도 현재 위치를 저장합니다. 저장 파일은 Godot `user://yard_save.json`에 있습니다. 체크포인트와 종료 위치는 별도로 저장됩니다. 공중에서 이어하기는 속도 0에서 재개됩니다.

## 구현 범위

- 깊이 축을 제한한 CharacterBody3D 이동과 고정 각도 추적 카메라
- 일반 점프 / 2단 점프, 0.11초 코요테 타임, 0.13초 입력 버퍼
- 참고 외형을 반영한 단순화된 3D 강아지, 이동·수직 도약·2단 도약·낙하·착지 동작
- 수동 배치한 평상·상자·의자·장독대·이불 발판
- 배변 체크포인트 1개, 지붕 도착 표시, 진행 저장

현재는 조작과 경로를 검증하는 짧은 그레이박스입니다. **10분 분량 및 난이도는 사람의 플레이테스트로 조정해야 합니다.** 최종 아트, 사운드, 움직이는 발판, 구름 구간, 할머니 엔딩은 포함하지 않았습니다.

## 검증

```sh
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --script tests/smoke.gd --fixed-fps 60
```

실제 물리 입력으로 발판 20개의 인접 구간 점프·착지를 각각 검증하고, 체크포인트와 위치 저장의 왕복 복원을 확인합니다. 전체 구간의 연속 무실수 플레이나 체감 난이도를 검증하는 테스트는 아닙니다. 테스트는 기존 저장 파일을 보존합니다.

우선 플레이하면서 착지 가독성, 재시도 의욕, 2단 점프 타이밍을 확인한 뒤 맵을 확장합니다.

## 할머니집 아트 플레이 시안

`yard_art.tscn`을 열고 **F6**으로 실행합니다. 기존 F5 프로토타입과 저장 데이터는 그대로 유지됩니다.

```sh
/Applications/Godot.app/Contents/MacOS/Godot --path /Users/iyeseul/Documents/yeaseul/ddong_puppy res://yard_art.tscn
```

- A/D 또는 방향키: 이동, Space: 2단 점프, R: 마당으로, F2: 충돌면 표시.
- 생성 이미지 한 장과 공통 3D 강아지 모델, 이미지 좌표에 맞춘 단순 충돌체를 결합한 시안입니다.
- 사망 없이 하단 지형이나 연속된 바닥에 착지합니다. 별도 저장은 하지 않습니다.
- 전경 분리, 시차, 카메라 상승, 최종 강아지 및 정교한 지붕 충돌은 후속 작업입니다.
- 이미지: `assets/environment/grandma_yard_v1.png` (내장 image_gen 생성).
- 생성 프롬프트 요약: 한국 시골의 파란 기와집, 장독대·돌담·평상·의자·나무가 자연스럽게 연결된 측면 2.5D 게임 환경. 사진 질감과 따뜻한 여름빛, 산 배경, 초록 부엌. 캐릭터·문자·UI·공중 발판 제외.

## 메인 로비 / 판타지 미술 시안

이제 **F5는 메인 로비**로 시작합니다. 사용자가 제공한 흰 강아지 이미지를 `assets/ui/lobby.png`에 보관해 로비 배경으로 사용합니다. 산책 시작은 새 아트 장면, 조작 연습은 기존 코스로 연결됩니다. 새 아트 장면에서 ESC로 로비에 돌아옵니다.

플레이 배경은 `assets/environment/grandma_fantasy_v2.png`입니다. 내장 image_gen으로 생성했으며 프롬프트는 한국 시골 판타지, 금빛 노을·살구색 구름·푸른 원경, 연결된 한옥·돌담·장독대와 구름 위 마을, 측면 게임 구도, 캐릭터와 UI 제외입니다.

현재 플레이 배경은 단일 이미지이며 강아지와 충돌체는 3D입니다. 최종 강아지, 입체 환경 모델, 독립 배경 레이어와 시차는 아직 구현하지 않았습니다.

### 착지 가독성 / 상승 카메라

아트 장면은 카메라 폭을 16에서 8.5로 좁히고 강아지의 높이와 좌우 위치를 부드럽게 추적합니다. 충돌면과 일치하는 얇은 3D 지형, 밝은 윗면, 착지 상태에서 가까운 상단 발판 안내를 추가했습니다. 현재·최고 높이도 표시합니다. 배경은 여전히 단일 이미지이며 전체 등반 경로의 체감 난이도는 플레이 검증이 필요합니다.

## 입체 수직 코스 (현재 산책 시작)

로비의 산책 시작은 `vertical_yard.tscn`으로 연결됩니다. 장독대 → 돌담 → 평상 → 기와지붕 → 나뭇가지로 이어지는 20.1m 코스입니다. 14개 착지 지형의 외형과 충돌체를 함께 생성하고, 집·기둥·나무·암반이 코스를 지지하도록 구성했습니다. 카메라는 세계의 일부만 보여주며 강아지를 따라 상승·하강합니다. 추락 시 아래 지형이나 기본 바닥에 착지합니다.

이 버전은 공간 구조를 검증하는 단순 3D 모델 단계입니다. 로비 수준의 재질·식생·원경·강아지 모델은 아직 적용하지 않았습니다. 예전 단일 이미지 장면은 `yard_art.tscn`에 보존하지만 산책 시작에서는 사용하지 않습니다.

검증: `Godot --headless --log-file /tmp/vertical-test.log --path . --script tests/vertical_yard.gd --fixed-fps 60`. 14개 인접 구간의 실제 점프·착지와 양쪽 끝에서 바닥으로 추락 후 착지를 확인합니다. 전체 연속 등반 난이도를 보장하는 테스트는 아닙니다.


## 주인공 강아지 / 수직 점프

`scripts/dog_visual.gd`에서 옷과 장비가 없는 흰 강아지 모델을 생성합니다. 기존 코스와 마당 모두 같은 캐릭터를 사용합니다. Space만 누르면 앞쪽 밀림 없이 위로 점프하며, A/D를 함께 누르면 좌우 조종이 가능합니다.

- 모델: `assets/characters/dog/white_puppy_v2.glb`
- 미리보기: `dog_preview.tscn`을 F6으로 실행
- 제작 방식과 한계: `assets/characters/dog/README.md`
- 수직 점프 검증은 `tests/smoke.gd`, GLB 재수입과 동작 검증은 `tests/dog_asset.gd`.

### 직접 제작한 생활용품

`scenes/props/jar.tscn`, `jangdokdae.tscn`, `cushion.tscn`은 재사용 가능한 절차적 3D 소품입니다. 항아리는 회전 단면으로 만든 둥근 몸통과 납작한 뚜껑, 장독대는 돌 받침과 크기가 다른 항아리 3개, 방석은 둥근 모서리와 가장자리 장식으로 구성됩니다. 시작 구간의 항아리 → 장독대 → 방석 얹은 평상에 적용했습니다. 외부 모델이나 텍스처는 사용하지 않았으며 `.glb`가 아닌 Godot 장면으로 제공합니다.

교체 후 전체 14개 인접 구간 점프·착지 및 양쪽 끝 바닥 착지 테스트 통과. 이 환경에서 창 렌더링 실행이 실패하여 화면 캡처를 통한 시각 검수는 수행하지 못했습니다.

### 높이별 난이도와 소품 변형

코스를 25.3m로 확장했습니다. 초반은 높이 차 1.1~1.4m, 중반은 1.7~2.0m, 후반은 2.2~2.3m이며 후반 좌우 간격은 3.2~3.4m로 구성했습니다. 후반의 지형 폭은 약 0.9~1.1m로 좁아져 2단 점프와 착지 조정이 필요합니다. 항아리 뚜껑과 방석의 실제 착지 폭은 본체 폭보다 작습니다.

`yard_prop.gd`의 `variant`(0~2)로 소품을 바꿉니다. 항아리는 둥근 갈색/좁은 어깨의 흑갈색/배가 넓은 황토색, 장독대는 받침 색과 항아리 개수·배열, 방석은 붉은 사각/초록 원형/황토색 장식 사각으로 구분합니다. 경로 높이에 따라 변형과 크기를 지정하므로 재실행해도 지형이 바뀌지 않습니다.

수정 후 14개 인접 구간의 점프·착지 및 양 끝 바닥 착지 테스트 통과. 체감 난이도는 사용자 플레이로 추가 조정합니다.

### 가져온 음식 에셋 무작위 배치

사용자가 제공한 `drive-download-20260930T062544Z-1-001`의 glTF 36개를 `assets/imported/food_pack`으로 복사했습니다. 의존 데이터는 glTF에 포함돼 있으며 원본은 변경하지 않았습니다. `food_scatter.gd`가 산책 진입마다 전체 모델 순서를 섞고, 크기와 Y축 회전을 달리해 경로 옆 나무 받침 12곳에 3개씩 배치합니다. 모델 바운딩 박스로 바닥과 크기를 정렬합니다. 현재는 충돌 없는 장식이며 기존 등반 지형과 난이도는 유지합니다.

36개 모델 생성과 14개 점프·착지, 양쪽 끝 추락 후 바닥 착지 테스트를 확인했습니다.

### 음식은 등반 지형으로 변경

이전 장식용 나무 받침과 음식 배치는 제거했습니다. 음식 36개를 장애물 코스 위의 실제 등반 지형으로 연결합니다. 산책마다 음식 순서와 코스 위치가 달라집니다. 초반에는 넓고 낮고 가까운 착지점을, 후반에는 좁고 높고 간격이 큰 착지점을 만들며 각 모델의 실제 착지 폭까지 다음 위치 계산에 반영합니다. 음식은 최대 폭과 깊이에 맞춘 균일 스케일을 사용해 원본 비율을 유지합니다. 외형을 찌그러뜨리지 않으면서 울퉁불퉁한 음식도 안정적으로 밟을 수 있도록 모델 상단에 실제 너비에 맞는 얇은 착지 충돌면을 둡니다. 검증은 `tests/food_route.gd`로 장애물 14개와 음식 36개, 총 50개 인접 점프를 확인합니다.

### 첫 맵 세로 노을 배경

사용자 제공 이미지를 `assets/environment/map01_vertical_sunset.png`에 저장했습니다. 원본 비율을 유지하며 화면 너비를 덮고, 카메라 높이에 따라 이미지 아래쪽 마을에서 위쪽 하늘까지 이동합니다. 하강 시 다시 아래쪽 풍경을 보여줍니다. 충돌은 없고 실제 지형보다 뒤에 배치합니다. `tests/background_scroll.gd`에서 시작·중간·정상·하강 위치의 화면 덮임과 스크롤 방향을 검증합니다.


## 흰 강아지 v2 / 기본 바닥

스카프·배낭·나침반 등 장비를 모두 제거하고, 몸통·얼굴의 곡면과 주둥이·볼·발·꼬리 비율을 수정했습니다. 이동과 수직 점프 동작은 유지합니다. `scripts/solid_ground.gd`는 윗면 Y=0을 유지하면서 아래로 40m, 가로 80m의 흙 지형을 채웁니다. 기본 코스·입체 산책·이전 마당 시안에 공통 적용했습니다. 실제 산책 화면은 `assets/characters/dog/yard-preview-v2.png`에서 볼 수 있습니다.

### 임시 구조물 제거

현재 산책 맵에서 코드로 만들었던 집·창문·기둥·나무줄기·암반과 지붕·가지·평상 받침을 제거했습니다. 기존 지붕·가지·평상 착지 지점은 방석으로 대체하고, 항아리 밑의 임시 판자도 없앴습니다. 보내준 세로 배경, 기본 바닥, 항아리·장독대·방석·음식 등반 지형을 유지합니다. 장독대 자체의 돌 받침은 소품 구성 일부입니다. 무작위 음식 배열 3회의 전체 50구간 점프·착지 및 양 끝 바닥 착지, 배경 상승·하강 검증을 통과했습니다.
